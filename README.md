# XYDROGEN AI

Evidence-aware educational website about mitochondrial biology and the emerging science of molecular hydrogen.

> Educational content only. Not medical advice. See [PRIVACY-AND-TERMS.md](PRIVACY-AND-TERMS.md).

## Stack
Static single-page site (`index.html`). No build step.

## Run locally
```bash
npm run dev   # npx serve .
```

## Deploy
Deployed on Vercel. `vercel.json` sets `outputDirectory` to `.` so the repo root is served as-is.
